# AdaCore

> AdaCore is a software company with 30+ years of experience building compilation, static and dynamic analysis, and formal-verification toolchains for reliable, safe, and secure software in safety- and mission-critical systems (aerospace, defense, rail, automotive, energy, telecom, finance, medical). AdaCore is a compiler and toolchain vendor and does not publish a hosted REST API or API client SDKs.

## Products
- GNAT Pro: Ada, C/C++, and Rust compilation toolchain
- SPARK Pro: formal proof / formal verification for the SPARK subset of Ada
- GNAT Static Analysis and CodeSonar (C/C++)
- GNAT Dynamic Analysis Suite
- GNAT Studio: Ada IDE, plus the open-source Ada Language Server and VS Code extension
